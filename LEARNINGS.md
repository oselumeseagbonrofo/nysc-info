# Approved lessons

The lessons for this project. Read them at session start. If lessons live at
machine level, read those too; on conflict, this project-specific copy wins.

One lesson per entry, captured on the incident, never on a schedule, no
journal. Format, one lesson:

- what failed
- why it failed
- the correct thing to do
- scope: `general` | `stack:<name>` | `project:<name>`

Read lessons whose scope matches the current work. A React lesson is noise in
a Go project; a Go lesson is noise in a React project. General lessons read
everywhere.

An agent may draft a lesson. The user approves or kills it before it lands.
Project-specific learnings also live in `learnings/`.
